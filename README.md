# BWI-Chat 💬
La messagerie pour tous les réseaux
Fait par Jockeur, NSI Coder et TheLouton
2024-2025

**Plateforme de messagerie pour toutes les situations.**

Ce projet se distingue des autres messageries par sa spécialité insolite. Vous pouvez l’utiliser dans presque n’importe quelle situation, même sans forfait ni Wi-Fi ! Parfait pour partager des fichiers lourds sans exploser votre forfait ou pour vos excursions en forêt profonde et autres aventures de l’extrême !

**D’où vient le nom ?**

Le nom vient d’une origine simple, le désir d’avoir une plateforme unique qui exploite le potentiel de tous les réseaux existants sur vos appareils, d’où le nom BWI-Chat pour BluetoothWi-FiInternet-Chat.

**Les objectifs du projet**
* Envoi de messages
* Recevoir les messages
* Stocker les messages quelque part
* Cryptage de messages
* Système d’état du message (En attente d’envoi, Reçu, Lu)
* Système de réponse à un message spécifique *(Optionnel)*
* Système d’envoi par différents protocoles *(Optionnel)*
